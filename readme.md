# Minecraft Server Website

Welcome to the official website of our Minecraft server.
This website is designed to keep players informed, connected, and updated with everything happening on the server.

---

## Features

* Server News & Updates – Stay updated with the latest changes, announcements, and events
* Rules Page – Read and understand the server rules before playing
* Server Information – View server IP address, version, and connection details
* Downloads – Access required mods or resource packs
* Live Status – Check if the server is online and see current player count
* Discord Integration – Join the community Discord server
* Staff Applications – Apply for staff roles or whitelist access
* Events & Screenshots – View past events and community screenshots

---

## Pages

* Home – Overview of the server and quick information
* About Server – Detailed information about the server
* Rules – Server rules and guidelines
* Updates – News, changelogs, and announcements
* Store – Optional donation or rank store
* Staff Team – List of server staff members
* Join Discord – Link to the community Discord server
